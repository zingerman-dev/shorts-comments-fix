# Privacy policy — Shorts Comments Fix for YouTube

_Last updated: September 13, 2026_

Shorts Comments Fix does not collect, store, sell or share any personal data.

- The extension runs only on www.youtube.com, inside the YouTube page.
- It looks at YouTube's own comment requests on Shorts pages. When comments arrive for a short you have already scrolled past, it asks YouTube for the comments of the current short instead, the same way the YouTube page does.
- It sends nothing to the developer or to any third party. There is no analytics, no tracking and no remote code.
- An optional debug mode only writes messages to your browser console and is turned on by you.

# Политика конфиденциальности — Shorts Comments Fix для YouTube

_Обновлено: 13 сентября 2026 г._

Shorts Comments Fix не собирает, не хранит, не продаёт и никому не передаёт персональные данные.

- Расширение работает только на www.youtube.com, внутри страницы YouTube.
- Оно следит за собственными запросами комментариев YouTube на страницах Shorts. Если комментарии пришли для уже пролистанного ролика, расширение запрашивает у YouTube комментарии текущего ролика — так же, как это делает сама страница.
- Расширение ничего не отправляет разработчику или третьим лицам. Нет аналитики, отслеживания и удалённого кода.
- Необязательный режим отладки только выводит сообщения в консоль вашего браузера и включается вами.
